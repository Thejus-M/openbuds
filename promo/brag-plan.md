# brag plan — Galaxy Buds2 on Linux

- **Format:** vertical 1080x1920, 30fps, 27s (810 frames). Music on, no voice.
- **Angle:** "Everything the phone app does, now in your Linux bar." Each beat shows one real control from the home.buds panel, then openbuds proves it works on any desktop.
- **Tone:** app-store feature cards, punchy. Smooth slides, cuts on the beat.
- **Identity:** Omarchy matte-black theme — bg `#121212`, card `#1e1e1e`, fg `#bebebe`, accent `#e68e0d`, red `#D35F5F`. Font JetBrainsMono Nerd Font. Glyphs from `Model.G`. Drawn earbud mark from `BudsMark.qml`.
- **Music:** 120 BPM (beat 0.5s), A minor, synthesized: kick, hat, sub bass, pluck arp. Soft tick on each cut, same key.
- **Data:** battery values 99 / 73 / 94 are illustrative. No personal data.
- **Safe zone:** readable text between y 250 and 1536.
